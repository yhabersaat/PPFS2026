# PPFS Assistant

Assistant for Power Platform French Summit 2026 attendees: agenda, sessions, speakers, sponsors, registration and practical information, based on the official website, and technical answers from Microsoft Learn.

PPFS Assistant is a Microsoft Copilot Studio agent (GitHub Copilot harness / CLI Copilot authoring) built from the specification in [`specs/ppfs-assistant.md`](specs/ppfs-assistant.md). It answers in the language of the attendee's latest message (English or French, formal *vous* form in French), keeps answers short, never invents times, rooms, speakers, prices or addresses, and politely declines off-topic questions.

## How to update the agent with the plugin

The agent is maintained with the Copilot Studio plugin for GitHub Copilot CLI (`copilot-studio-plugin` / `mcs-assistant`), which drives the Power Platform CLI (`pac copilot`). Prerequisites: PAC CLI 2.13.1 or later, an auth profile for the environment above (`pac auth select`), and the GitHub Copilot CLI with the plugin installed.

1. Pull the latest cloud state before editing:
   ```powershell
   pac copilot pull --project-dir .\ppfs-assistant
   ```
2. Edit the YAML files in `ppfs-assistant/` (for example `settings.mcs.yml` for instructions or model, `capabilities/knowledge/` to add a source, `capabilities/tools/` for tools). In GitHub Copilot CLI you can simply describe the change and let the plugin's skills (`create-agent`, `add-knowledge`, `push-agent`, `publish-agent`) apply it.
3. Push the changes, then pull again to confirm the round trip:
   ```powershell
   pac copilot push --project-dir .\ppfs-assistant
   pac copilot pull --project-dir .\ppfs-assistant
   ```
4. Publish when ready (changes are drafts until published):
   ```powershell
   pac copilot publish --bot 673b8a87-7060-4424-97b5-cd843907785e --environment 3bd8a3f5-8e4c-eb9f-b86b-a7996cc5eb06
   ```
5. Commit the updated files on a feature branch and open a pull request to `main`.

Notes verified in this environment: channel entries must be written as `- channelId: MsTeams` objects, `supportedLanguages` must be a block list, and uploaded-file sidecar descriptions are reset to defaults by the CLI. Never commit `ppfs-assistant/.mcs/conn.json` (it is covered by `.mcs/.gitignore`).
